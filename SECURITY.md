# Security Policy

## Supported Versions
Web3Shield is in early development. All versions are considered active and  
security issues will be addressed as quickly as possible.

## Reporting a Vulnerability
If you discover a vulnerability, please report it privately.

Email: coderunner2026@gmail.com  
Do not open a public GitHub issue for sensitive security problems.

## What to Include
- Description of the issue  
- Steps to reproduce  
- Potential impact  
- Any suggested fixes  

Thank you for helping keep Web3 users safe.
